# দৈনিক হিসাব (Daily Hisab)

Bangla Personal Finance & Expense Tracker Android App.

## Features
- 📊 Track income & expenses in Bangla
- 🔐 Email/password authentication
- 👆 Biometric lock (Face ID / Fingerprint)
- 📁 Category management
- 📈 Reports & charts
- 🌙 Dark/Light theme
- 💾 Local storage (Room Database)
- 🎨 Premium Material 3 Design

## Build
```bash
./gradlew assembleDebug
./gradlew assembleRelease
```
